# avm-plugin-java

avm's native OpenJDK provider — version listing (live from the
[foojay Disco API](https://api.foojay.io), Eclipse Temurin builds only),
install, and `JAVA_HOME` resolution, for
[avm](https://github.com/PrajaNova/avm).

Speaks avm's plugin protocol, documented in the main repo.

```bash
cargo build --release
# binary at target/release/avm-plugin-java
```
